# 銀行・カード明細CSV変換ツール（無料・ブラウザ内で完結）

銀行やカードの明細CSVを、会計ソフトへ取り込みやすい `日付,摘要,金額` の3列に整えます。

**公開ページ**: https://naporit0742.github.io/meisai-csv-converter/

## 明細はどこにも送信されません

読み込み・変換・ダウンロードは、すべて利用中のブラウザ内で完結します。

- サーバーへ送る通信コードがありません（`fetch` も `XMLHttpRequest` も使っていません）
- アクセス解析、外部フォント、外部CDNを一切読み込みません
- `Content-Security-Policy` の `connect-src 'none'` で、外部接続そのものを禁止しています

「送信しない」は説明ではなく、このリポジトリのソースで確認できます。

## 対応している表記

| 種類 | 例 |
|---|---|
| 文字コード | Shift_JIS、UTF-8、UTF-8（BOM付き） |
| 日付 | `2026/1/5` `20260105` `R8.1.5` `令和8年1月5日` `H31.4.30` `２０２６／１／５` |
| 金額 | `1,234` `△440` `▲1,000` `(2,500)` `1000-` `￥3,300` `＋１，２５０` |
| 金額の持ち方 | 符号付き1列、符号なし1列、出金列と入金列の2列 |
| 見出し行 | 先頭に口座情報などの前置きがあっても、20行目までから自動で探します |

摘要の半角カナは全角に、全角英数は半角に整えます。

## 対応していないもの

PDF、Excel（`.xlsx`）、金融機関からの明細の自動取得、税務・会計上の判断。5MBを超えるファイル。

## 使い方

ページを開いて、CSVをドラッグ&ドロップするだけです。手元の明細を使わずに、同梱の架空サンプル3種でも試せます。

変換前に、**文字コード・見出し行・どの列を何と判定したか**を画面に表示します。自動判定を鵜呑みにせず確認してから保存してください。

読めない行があった場合は、行番号と理由を画面に表示します。会計ソフトへ取り込む前に、必ず元の明細と合計を突き合わせてください。

## ローカルで動かす

```
python -m http.server 8000
```

ビルド、npm、外部CDNは不要です。`file://` で直接開いても動きます。

動作テストは [`tests.html`](tests.html) をブラウザで開くと実行され、結果が画面に出ます。

## サンプルについて

`samples/` の3ファイルはすべて架空データです。実在の金融機関・個人・法人とは関係ありません。

## 免責

変換結果が、すべての金融機関・会計ソフトの形式に合うことを保証するものではありません。
取り込む前に、元の明細と行数・期間・入出金合計を照合し、利用者の責任で内容を確認してください。
本ツールは税務・会計上の判断を行いません。
